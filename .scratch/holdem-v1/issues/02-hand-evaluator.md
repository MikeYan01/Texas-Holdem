# 02: 7 张牌求值器

**What to build:** 给定七张牌,判断它构成的最好的五张牌有多强,强到可以拿两手牌直接比大小、并且能分辨出"完全一样强"(即平分底池)。这是整个游戏的正确性地基:谁赢、谁分池、以及界面上"两对,A 带 K"这句话,全都由它决定。

这一票没有界面。它的验收方式是**证明它是对的**——把全部 133,784,560 种七张牌组合跑一遍,九个牌型的出现次数必须与公开值分毫不差。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 求值函数接受七张牌,返回**单个可比较的整数**;两个相等的返回值意味着平分底池。不返回"类别 + 踢脚数组"(见 ADR-0004)
- [ ] 大小方向(数值越大越强,还是越小越强)在接口上明确写死,并有测试固定
- [ ] 可以从返回值取出牌型类别与关键牌信息,足以支撑后续生成中文文案(本票不做文案)
- [ ] 穷举全部 C(52,7) = 133,784,560 手牌,九个牌型频次与公开值完全一致:同花顺 41,584 / 四条 224,848 / 葫芦 3,473,184 / 同花 4,047,644 / 顺子 6,180,020 / 三条 6,461,620 / 两对 31,433,400 / 一对 58,627,800 / 高牌 23,294,460
- [ ] 上述穷举验证在 CI 中运行(参考耗时约 37 秒)
- [ ] 与 `phe` 的差分测试:数十万次随机七张牌的两两排序,零分歧;数十万次摊牌的平局判定,零不符
- [ ] 九个已知陷阱各有一条显式测试:
  - [ ] 同花且有顺子 ≠ 同花顺(`Ah Kh Qh Jh 9h Ts Tc` 只是同花)
  - [ ] A-2-3-4-5 轮子顺
  - [ ] 轮子同花顺
  - [ ] A 不回绕(`Q K A 2 3` 不是顺子)
  - [ ] 两组三条构成葫芦
  - [ ] 七张牌出现三个对子时,两对的踢脚可能是第三对的点数
  - [ ] 四条的踢脚可能来自一个对子
  - [ ] 六张或七张同花时取最大的五张
  - [ ] 两手实质相同的牌返回相等的值
- [ ] 一条只防数量级退化、不追求精确数字的性能基线测试
- [ ] 求值器位于引擎侧,零运行时依赖

**参考:** `.scratch/poker-eval-reference/`(`myeval.js`、`exhaustive.js`、`headtohead.js` 及 README)是调查阶段留下的**正确性参照物与性能基线**,不是要照搬的代码。本票走 TDD 重写。
