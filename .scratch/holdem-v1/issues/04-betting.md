# 04: 下注

**What to build:** 牌局从这一票开始真的能打。每手 Hand 由 SB 和 BB 强制投入起头,Button 每手顺时针移动一位;轮到你时可以弃牌、过牌、跟注或加注,加注旁边有「1/2 池」「满池」「All-in」三个预设档位和一个微调滑块;不合法的行动直接不可点。一个下注轮在该结束时结束,牌局进入下一个 Street。

对手此时仍是脚本化策略(如"永远跟注"),不是真 Bot——那是第 07、08 票的事。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 支持的行动:弃牌、过牌、跟注、下注、加注、all-in
- [ ] 每手 Hand 开始时由 Button 左侧两个 Seat 投入 SB 1 / BB 2;盲注全程不涨
- [ ] Button 在每手 Hand 开始时顺时针移动一位
- [ ] preflop 的首个行动者是 BB 左侧的 Seat;flop 之后的首个行动者是 Button 左侧仍在局中的 Seat
- [ ] **合法行动由引擎计算并挂在 state 上**;界面只按它启用/禁用按钮,自己不判断合法性
- [ ] 引擎给出跟注额、最小加注额、all-in 上限,以及三个预设档位的**具体金额**(见 ADR-0001:这些计算必须在引擎里,不能在组件里)
- [ ] 最小加注规则正确:加注幅度不得小于上一次加注的幅度
- [ ] Stack 不足以完成一次完整加注时仍可 all-in
- [ ] 下注轮在所有未弃牌且未 all-in 的 Seat 都行动过、且投入额相等时结束
- [ ] 有人加注会重开其余 Seat 的行动权
- [ ] 只剩一个 Seat 未弃牌时,立即结算并把底池给它,**不再发任何公共牌**
- [ ] 界面提供「弃牌 / 过牌·跟注 / 加注」三个主按钮 + 三个预设档位 + 滑块
- [ ] 没有任何倒计时
- [ ] 引擎测试注入**脚本化策略**(如"永远跟注"、"某个 Seat 在 flop 加注满池"),不使用真 Bot
- [ ] 测试直接构造起始局面覆盖:下注轮终止、加注重开行动权、最小加注边界、预设档位金额、只剩一人时立即结算
