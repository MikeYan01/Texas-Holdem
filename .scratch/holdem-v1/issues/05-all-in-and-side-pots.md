# 05: All-in 与边池

**What to build:** 有人推光了筹码之后,一切仍然正确。短码 all-in 时,别人多下的部分自动形成他无权争夺的 Side Pot;剩余玩家全部 all-in 后,底牌先亮出来,剩余公共牌一张一张带停顿地发完;每个池子由**有资格争夺它的 Seat 中最强的牌**赢走;打平时底池被平分,不能整除的余数按一条确定规则归属,绝不凭空消失。

这是全项目最容易写错的一票。它也是 6 人桌真正的复杂度所在——正因为如此,当初才选了 6-max 而不是回避它。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 某个 Seat all-in 且其 Stack 盖不住当前下注额时,超出部分形成 Side Pot,该 Seat 无权争夺
- [ ] 一手 Hand 内可以同时存在多个 Side Pot,且顺序与归属正确
- [ ] 每个池子(主池与各 Side Pot)**独立结算**,由有资格争夺它的 Seat 中牌力最强者赢走
- [ ] 摊牌打平时底池被平分
- [ ] 平分产生的余数按确定规则归属:从 Button 左侧起第一个赢家。**总额必须守恒**,余数不得丢弃
- [ ] 剩余未弃牌的 Seat 全部 all-in 后,不再有下注轮,剩余公共牌被发完
- [ ] 界面在上述情形下先亮出这些 Seat 的底牌,再一张一张带停顿地发出剩余公共牌(节奏由界面控制,引擎不 sleep)
- [ ] 界面在存在 Side Pot 时分别显示各个池子的金额
- [ ] 界面把已弃牌的 Seat 明显置灰
- [ ] 测试直接构造多人不同码量 all-in 的局面,断言最终筹码分配,覆盖:
  - [ ] 单个 Side Pot
  - [ ] 两个以上 Side Pot 并存
  - [ ] 短码赢下主池但无权争 Side Pot
  - [ ] Side Pot 与平分同时发生
  - [ ] 余数归属
- [ ] 一条守恒断言:任何一手 Hand 结算前后,所有 Seat 的 Stack 之和加上池中筹码保持不变
