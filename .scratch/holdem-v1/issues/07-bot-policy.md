# 07: Bot 决策

**What to build:** 给定一个 Seat 能看到的局面,决定弃牌、跟注还是加注。五种性格——TAG、LAG、Calling Station、Rock、Maniac——共用**同一套逻辑**,区别只是几组常数(见 ADR-0003)。

核心规则:算出 Equity,与 Pot Odds(`跟注额 ÷ (底池 + 跟注额)`)比较,而不是与一个固定数字比较。这条存在的全部理由是防住一个具体的、人一眼就能看穿的蠢错:底池已有 100、跟 2 就能参与时,绝对阈值会把这个池子扔掉。

本票不接进牌桌,那是第 08 票。

**Blocked by:** 04、06

**Status:** ready-for-agent

- [x] 决策函数接受一个 `view` 和一个性格,返回一个 action
- [x] `view` 是从引擎 state 派生的投影,**在类型上就不包含其他 Seat 的底牌**——让作弊成为类型错误,而不是靠纪律
- [x] 决策规则:Equity 低于 Pot Odds 则弃牌;高于则跟注;高出足够余量则加注
- [x] 五种性格由**常数偏移**实现,不是五套独立逻辑:门槛高低(松/紧)、升级为加注所需的余量(被动/激进)、翻牌前入池范围宽窄
- [x] Bot 不直接使用真实 Equity,叠加每个 Bot 自己的噪声——否则它们跟注过多且显得机械
- [x] 下注尺度有变化,不是永远一个固定数
- [x] **Pot Odds 属性测试**:构造底池远大于跟注额的 view,断言**任何**性格的 Bot 都不弃牌
- [x] **性格排序测试**:同一批 view 下,Rock 的入池率低于 Calling Station,Maniac 的加注率高于 TAG。断言的是**相对次序**,不是具体数字,否则测试会锁死调参
- [x] **合法性测试**:对大量随机 view,返回的 action 永远是引擎认可的合法行动之一
- [x] **视野封闭测试**:确认从 `view` 构造不出其他 Seat 的底牌
- [x] RNG 注入,种子固定时决策完全可复现

## Comments

**实现完成。有一处规则细化:**

「任何性格的 Bot 在底池远大于跟注额时都不弃牌」这条属性测试,与「Rock 的翻牌前入池范围要很窄」直接冲突——如果门槛是 `Pot Odds + 常数余量`,Rock 的 0.22 余量会让它在 pot odds 只有 1.96% 时仍然弃掉 25% 胜率的牌,而这正是 ADR-0003 要防的那个蠢错。

解决办法:**余量与价格成正比,而不是一笔固定的税。** 门槛取两种形式里较小的一个:

- `潜在赔率 + 常数余量`(在正常价位下生效,性格差异就体现在这里)
- `潜在赔率 × (1 + 余量 / 0.1)`(在便宜价位下生效)

两者在「跟注花掉底池十分之一」这个参考价位上完全相等,所以没有魔法常数;高于它用加法式,低于它用比例式。这样既保住了 ADR-0003 的属性,也保住了性格之间的相对次序。见 `src/bots/decide.ts` 的 `callThresholdFor`。
