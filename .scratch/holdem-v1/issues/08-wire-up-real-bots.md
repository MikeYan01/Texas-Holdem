# 08: 接上真 Bot

**What to build:** 第一次能真的坐下来打。牌桌上的五个对手从脚本化策略换成五个真 Bot,每人一种性格;它们行动前会停顿一下,牌桌旁有一条记录告诉你刚才发生了什么。

那个停顿不是装饰。Bot 的决策是瞬时的,不加延迟的话,你一按弃牌,屏幕会在一帧之内跳到下一手牌的你——中间五个人做了什么你完全没看见。而德扑的信息几乎全在别人的行动序列里。

**Blocked by:** 05、07

**Status:** ready-for-agent

- [ ] 五个 Bot 各占一个 Seat,性格分别为 TAG、LAG、Calling Station、Rock、Maniac,座位随机
- [ ] Player 与五个 Bot 的座位分配在每个 Session 开始时随机
- [ ] 每个 Bot 行动前有 600–1200ms 的随机延迟
- [ ] **延迟由界面实现,不在引擎内**——引擎仍然不含任何计时器
- [ ] 牌桌上有一条行动记录,按发生顺序显示每个 Seat 做了什么及金额(例如"Seat 3 加注到 12")
- [ ] 行动记录的文案在渲染层由引擎的结构化事件翻译成中文
- [ ] Bot 策略是**注入**引擎的依赖,引擎自身不 import 任何具体策略
- [ ] 打完一整手 Hand 全程可玩:发牌、四个 Street、Bot 依次行动、摊牌或提前结束、底池结算
- [ ] 连续打若干手不出现状态错乱、卡死或非法行动
