# 11: Player 的 Equity 显示

**What to build:** 轮到你行动时,界面告诉你当前赢下这手牌的概率。这是这个项目"训练味道"真正落地的地方,而它几乎是白送的——Bot 为了决策本来就要算这个数。

它不评判你的决策,不告诉你"你该弃牌"。那需要一个"正确决策"的基准,而定义正确就是求解器的问题,明确在范围之外。它只给你一个真实的数字,让你慢慢知道 K♠J♠ 在六人底池里到底值多少。

**Blocked by:** 04、06

**Status:** ready-for-agent

- [x] 轮到 Player 行动时,界面显示其当前 Equity
- [x] Equity 随 Street 推进而更新(新公共牌发出后重算)
- [x] Equity 的计算方式随 Street 变化对使用者透明(翻牌前查表、翻牌转牌蒙特卡洛、河牌精确枚举)
- [x] 数字的呈现说明它是"对当前仍在局中的对手数"的胜率,不产生歧义
- [x] 计算不阻塞界面:等待期间有明确的加载态,不出现卡顿或掉帧
- [x] 不显示任何决策建议或对错评价
- [x] 不泄露任何对手的具体底牌信息
