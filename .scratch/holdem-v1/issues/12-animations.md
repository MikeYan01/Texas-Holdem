# 12: 动画

**What to build:** 让牌桌看得懂。筹码从 Seat 推向底池、底池在结算时被推向赢家、牌被发出、当前行动者被高亮。

这些不是装饰,是**信息**:它们回答"钱去哪了"和"轮到谁了"。砍掉它们,数字会在屏幕上凭空突变,你就读不出这手牌发生了什么。(音效则相反——它不传递你看不到的信息,因此明确不做。)

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 筹码从 Seat 推向底池的动画
- [ ] 结算时底池推向赢家的动画
- [ ] 发底牌与发公共牌的动画
- [ ] 当前行动者的高亮,状态变化清晰可见
- [ ] 动画由引擎吐出的结构化事件驱动,**引擎内不含任何计时器或动画状态**
- [ ] 动画不阻塞游戏推进:快速连续操作时不会卡住或产生状态错乱
- [ ] 连续多手 Hand 之间动画正确重置,不残留上一手的状态
- [ ] 不做音效
