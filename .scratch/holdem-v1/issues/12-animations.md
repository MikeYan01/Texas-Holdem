# 12: 动画

**What to build:** 让牌桌看得懂。筹码从 Seat 推向底池、底池在结算时被推向赢家、牌被发出、当前行动者被高亮。

这些不是装饰,是**信息**:它们回答"钱去哪了"和"轮到谁了"。砍掉它们,数字会在屏幕上凭空突变,你就读不出这手牌发生了什么。(音效则相反——它不传递你看不到的信息,因此明确不做。)

**Blocked by:** 05

**Status:** ready-for-agent

- [x] 筹码从 Seat 推向底池的动画
- [x] 结算时底池推向赢家的动画
- [x] 发底牌与发公共牌的动画
- [x] 当前行动者的高亮,状态变化清晰可见
- [x] 动画由引擎吐出的结构化事件驱动,**引擎内不含任何计时器或动画状态**
- [x] 动画不阻塞游戏推进:快速连续操作时不会卡住或产生状态错乱
- [x] 连续多手 Hand 之间动画正确重置,不残留上一手的状态
- [x] 不做音效

## Comments

**实现完成。**

补一条布局上的硬约束,和动画同属「让牌桌看得懂」这件事:**牌桌屏固定为一个视口高,任何东西都不许把页面撑高。** 行动记录是无上限增长的(三十手的全部行动),原先它会把 grid 行撑高、连带把牌桌拉长,打到后面必须上下滚动才能看清谁在干什么。

现在 `.screen--table` 是 `height: 100vh; overflow: hidden`,`.layout` 的行固定为 `minmax(0, 1fr)`,只有 `.log__scroll` 一个滚动容器,并且自动贴底(读者往上翻时不打断)。headless 浏览器实测三十手全程 `scrollHeight === innerHeight`,溢出计数为 0。
