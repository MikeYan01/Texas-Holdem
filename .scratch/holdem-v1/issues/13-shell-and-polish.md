# 13: 收尾

**What to build:** 把游戏从"能打"变成"能交付"。一个极简的开始屏,一个像样的结算屏,以及一道防止你误手丢掉半局的保险。

阵容固定为五种性格各一个,**不做难度选择**:难度旋钮听着便宜,实际意味着每一档都要调参并验证 Bot 真的变强或变弱,那需要大量对局数据。而"五种性格各一"本身就是刻意设计的阵容——它保证你每局都同时面对紧手、松手、跟注站和疯子,信息量比一个笼统的滑块大得多。
