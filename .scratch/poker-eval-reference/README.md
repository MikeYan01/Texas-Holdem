# Poker evaluator / equity — 参考实现

这四个文件是一次 research 调查留下的**一手证据**,不是本项目的代码。它们支撑 ADR-0004 和 ADR-0005 的结论,保留下来是为了让那两个 ADR 的数字可以被复现,而不是只能相信转述。

实测环境:Apple M3 Pro (12 核) / macOS 26.6.2 / Node v26.7.0。

## 文件

| 文件 | 是什么 |
| --- | --- |
| `myeval.js` | 手写的 7 张牌求值器,85 行(73 行有效代码)。打包后 1,803 B / gzip 926 B,实测 4.1 M 次/秒。 |
| `exhaustive.js` | 穷举 **全部 C(52,7) = 133,784,560 手牌**,统计九个牌型频次并与公开值比对。37 秒跑完,结果完全一致。 |
| `headtohead.js` | 与 `phe` 的差分测试:30 万次随机对局排序,0 处分歧;30 万次摊牌的平局/分池判定,0 处不符。 |
| `eq2.js` | 蒙特卡洛 equity 循环。每次迭代**零分配**:扁平 `Int32Array` 牌堆、复用的 7 槽手牌数组、只抽所需张数的部分 Fisher-Yates。实测 0.72 µs/次。 |

## 复现

需要 `phe@0.6.0` 作为对照(它只在这里用作参照物,不是本项目的运行时依赖):

```sh
npm i phe@0.6.0
node exhaustive.js    # ~37s,验证 1.34 亿手牌的牌型频次
node headtohead.js    # 差分测试 + 吞吐对比
```

## 注意

这些是调查用的一次性脚本,**不是**要照搬进 `src/` 的代码:没有类型、没有测试、风格与本项目无关。真正的实现走 TDD 重写,把这里当作正确性的参照物和性能的基线。
