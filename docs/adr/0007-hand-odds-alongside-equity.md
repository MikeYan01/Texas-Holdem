# 成牌概率与 Equity 分开,并且处处精确

界面上给 Player 看的主要数字是 **Hand Odds(成牌概率)**:最终做成每种牌型的概率分布,只显示最高的五种。**Equity(胜率)**保留为角落里的一行。

两者回答的是不同的问题,而且后者贵得多:

- Equity 问「我会不会赢」,必须把对手发进去,所以只能抽样(ADR-0005)。
- Hand Odds 只问「我最后会拿到什么」,**与对手完全无关**,于是可以处处精确枚举。

| Street | 方法 | 枚举量 |
| --- | --- | --- |
| 翻牌前 | 查表(离线穷举) | 每手 C(50,5) = 2,118,760 |
| 翻牌 | 现场枚举 | C(47,2) = 1,081 |
| 转牌 | 现场枚举 | 46 |
| 河牌 | 已定型 | 1 |

翻牌前那张表由 `scripts/generate-preflop-hand-odds.ts` 生成:169 个规范起手牌 × 全部公共牌组合,3.58 亿次求值,48 秒。**存的是计数不是概率**,所以每格精确,并且「每行之和恒等于 C(50,5)」是一条可断言的性质。

## Considered Options

**只显示 Equity。** 否决:一个 28% 说明不了任何事。而「一对 45.9% / 两对 22.8% / 高牌 19.5% / 三条 4.5% / 顺子 3.1%」告诉你这手牌**会变成什么**,这正是新手需要建立的直觉——同花只在你真有同花可能时才出现在榜上,这件事本身就在教牌。

**显示全部九种牌型。** 否决:九行读不过来,而尾巴上那几个通常是 0.03% 量级。取前五,并且**丢掉概率为零的类别**而不是列成 0%。

**用蒙特卡洛算,和 Equity 共用一套循环。** 否决:翻牌之后样本空间小到枚举更快,抽样只是徒增噪声。这个数字不需要误差条。

**接口做成异步,和 `getEquity` 保持一致。** 否决:最坏情况 1,081 次求值,远低于一毫秒,永远不会需要 Web Worker。假装异步只会让每个调用点多背一个 `await`。

## Consequences

多了一张 17 KB 的生成数据(计数比概率占地方),换来翻牌前零耗时且精确。

最强的一条验证顺带落地了:把 169 手按发牌频率加权平均,必须复现随机七张牌的公开牌型频次——实测到小数点后三位完全吻合(一对 43.823%、两对 23.496%…)。任何一格算错都会在这里暴露,而它跑起来只要几毫秒。

Equity 没有删掉,因为 spec 用户故事 30 和 ADR-0005 的整条推理都建立在它之上;它只是不再是面板的主角。
